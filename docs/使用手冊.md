# ORCH 使用手冊（v0.21.0）

## 1. 登入

打開 ORCH 網址，輸入管理員給你的用戶名稱及密碼。連續輸入錯誤密碼會被暫時鎖定（預設 5 次，鎖定 15 分鐘）。閒置 30 分鐘會自動登出。右上角可切換語言（English／繁體中文／简体中文）及登出。頁尾顯示系統版本。

## 2. 角色

| 角色 | 可以做甚麼 |
|---|---|
| 管理員（admin） | 管理帳戶、指派模組審批人、保留期限設定、匯出權限清單。帳戶變更（例如新增管理員）需要另一名管理員批准。 |
| 編輯（editor） | 建立及修改 AI 草稿（產品頁、FAQ、跟進訊息、推廣活動等）、匯入店舖數據。 |
| 審批人（approver） | 在「審批收件箱」批准或拒絕草稿。只可審批被指派的模組，**不可審批自己寫的草稿**。 |

## 3. 主要頁面

| 頁面 | 用途 |
|---|---|
| 總覽 | 任務數量、逾期草稿提示 |
| 任務／事件 | ORCH 任務及事件記錄（唯讀） |
| ORCH 聊天 | 以店舖數據回答問題（唯讀，不會執行任何操作） |
| 銷售、內容、知識庫、商機、推廣、市場 | 建立各類 AI 草稿 |
| 審批收件箱 | 審批人批准／拒絕草稿，選擇發佈渠道 |
| 審計 | 已決定草稿的不可變審計記錄 |
| 匯入 | 上載店舖 CSV（產品、訂單） |
| 管理 | 用戶、審批人、保留期限、權限清單（只限管理員） |

## 4. 建立草稿（編輯）

1. 在「內容」等頁面選擇產品／類型及語言，按「建立草稿」。
2. 草稿進入「審批收件箱」，狀態為「待審批」，並顯示限期。
3. 可在審批前修改草稿；每次修改會產生新版本，審批人看到的是最新版本。

## 5. 審批草稿（審批人）

1. 打開「審批收件箱」，選擇草稿，閱讀內容及資料來源。
2. 批准：選擇發佈渠道，按「批准」。系統寫入不可變審計記錄（模擬發佈，不會對外發出）。
3. 拒絕：必須填寫原因。
4. 同一草稿只可被決定一次；如果兩人同時按批准，只有一人成功，另一人會看到「已不是待審批」。

## 6. 匯入店舖數據

在「匯入」頁上載產品及訂單 CSV（UTF-8 或 Big5）。匯入後聊天及草稿會使用匯入數據，並註明數據截至日期。可以隨時停用或重設匯入數據。

## 7. 權限清單（管理員）

「管理 → 權限清單」列出每個帳戶的角色、狀態及可審批的模組。按「匯出 CSV 檔」下載（UTF-8 BOM，可直接用 Excel 開啟）。每次匯出都會記錄在管治審計記錄中。詳見 [SOP.md](SOP.md) 第 5 節。

## 8. 常見問題

- **忘記密碼**：請管理員在「管理 → 用戶管理」申請重設密碼（需另一名管理員批准），或在伺服器執行 `python orch_auth.py reset-password <用戶名稱>`。
- **帳戶被鎖定**：等候鎖定時間結束，或由管理員執行 `python orch_auth.py unlock <用戶名稱>`。
- **看不到某個模組的草稿**：請管理員確認你已被指派為該模組的審批人。
- **附上圖片的聊天顯示「AI 供應商拒絕了請求（HTTP 404）」**：通常是圖片模型已被 OpenRouter 停用（伺服器日誌會顯示 `chat provider failure: kind=vision code=http status=404 model=…` 及「No endpoints found」）。請管理員在 `.env` 設定 `OPENROUTER_VISION_MODEL` 為現行模型（預設 `mistralai/mistral-medium-3.1`）並重新啟動，詳見 [安裝指南.md](安裝指南.md) 第 3 節。
